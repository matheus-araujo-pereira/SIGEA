\begin{resumo}[Abstract]
\begin{otherlanguage*}{english}
This document establishes the structural modeling and object-oriented design of the Intelligent Adverse Event Management System based on the Global Trigger Tool methodology (SIGEA-GTT), developed at the Federal University of Sergipe (UFS). Grounded in the formal precepts of the OMG UML 2.5.1 specification, SOLID software architecture principles, and the catalog of Gang of Four (GoF) and enterprise application design patterns, this work comprehensively documents all classes structuring the backend application in Java 21 and Spring Boot 3.3, as well as the reactive frontend architecture in TypeScript and Angular 18+. The document decomposes the system into strictly decoupled architectural layers: the Domain Layer, modeling the core JPA entities (\texttt{User}, \texttt{GttModule}, \texttt{GttTrigger}, \texttt{HarmSeverity}, \texttt{AcademicClass}, \texttt{Activity}, and \texttt{ActivitySubmission}) and their embedded/semi-structured JSONB value objects; the Persistence Layer, formalizing repository interfaces derived from Spring Data JPA; the Service Layer, encapsulating clinical business logic, ACID transaction management, and institutional domain validation (\texttt{@academico.ufs.br}); the REST Presentation Layer, detailing RESTful controllers, the Data Transfer Object (DTO) pattern, structural MapStruct mappers, and global exception handlers; and the frontend structural model, centered on Standalone Components, singleton services, and reactive state management via Angular Signals. Class diagrams are presented in native vector TikZ notation for each subsystem and architectural layer, accompanied by exhaustive descriptive dictionaries detailing attributes, methods, visibility markers, and multiplicities. Finally, bidirectional traceability matrices map the classes to all twenty-five functional requirements, use cases, physical relational database tables, and applied design patterns, demonstrating architectural robustness, high cohesion, and low coupling.

\end{resumo}
